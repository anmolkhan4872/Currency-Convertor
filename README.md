# Currency-Convertor
## About the project 
This is a currency convertor built using HTML, CSS, JavaScript. It allows users to enter an amount and convert between supported currencies.
## Technologies Used 
-HTML
-CSS
-JavaScript
## Features 
-Amount input
-Currency selection
-Currency conversion
-Simple user interface
